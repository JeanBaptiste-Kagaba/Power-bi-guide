# Power BI: A Practical Beginner's Guide

## About this project

I created this guide to make learning Power BI more practical and easier to follow. My aim is to help learners understand not only how to use Power BI, but also how to apply it when working with data.

The guide uses practical examples to introduce data analysis, visualisation, and DAX calculations.

## What you will learn

- Work with sales data in Power BI.
- Build visuals and explore data.
- Create DAX measures for sales, costs, profit, and other business indicators.
- Understand how filters affect calculations.
- Practise analytical techniques through step-by-step examples.

## Who is this guide for?

This resource is intended for beginners, students, aspiring data analysts, and professionals who want to strengthen their practical Power BI skills.

## Getting started

1. Download the PDF guide from this repository.
2. Open Power BI Desktop.
3. Follow the instructions and practise the examples.
4. Adapt the exercises to your own datasets as you gain confidence.
